# Wonders Vocabulary App

This workspace contains a handoff package for building a child-friendly English vocabulary learning app aligned to the `Wonders` curriculum.

Documents:

- `docs/PRD.md`: product goals, users, MVP scope, and acceptance criteria
- `docs/CONTENT_SPEC.md`: vocabulary entry schema, synonym explanation rules, and quiz content rules
- `docs/TECH_PLAN.md`: recommended technical architecture, data model, and milestone plan
- `docs/CODEX_HANDOFF.md`: a ready-to-use brief for Codex to start implementation

Recommended build priority:

1. Finalize MVP scope in `docs/PRD.md`
2. Use `docs/CONTENT_SPEC.md` to prepare source data and content format
3. Use `docs/TECH_PLAN.md` to scaffold the app
4. Give `docs/CODEX_HANDOFF.md` to Codex and begin development
