# Wonders Data Status

## Current status

The current MVP includes a small seed set for:

- Grade 3
- Unit 2
- Week 1
- 12 vocabulary entries

This is enough to validate the learning flow, but it is **not** yet a complete elementary `Wonders` vocabulary corpus.

## What is needed to make it complete

To claim the app includes **all elementary Wonders vocabulary**, the project needs a reliable source covering:

- Kindergarten through Grade 5, or the exact grade span the user wants
- all units
- all weeks
- each week's official target word list

## Important copyright note

`Wonders` is a commercial curriculum. We should avoid copying textbook passages, example sentences, or proprietary teaching text into the product unless the project owner has permission to do so.

The safest path is:

1. import only the official weekly word lists from a source the project owner is allowed to use
2. author original explanations and example sentences
3. keep source notes for each imported list

## Recommended next step

Provide one of these:

- a licensed/exported Wonders vocabulary list
- school-provided weekly vocabulary PDFs that the project owner is authorized to use
- a manually prepared spreadsheet with `grade / unit / week / word`

Once that source exists, the app can be expanded systematically.
