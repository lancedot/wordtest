# Wonders 词汇来源建议

## 当前结论

公开网络上能找到一些 `Wonders` 周词汇页面和 PDF，但大多是：

- 学校老师的公开网页
- 第三方教学资源
- 局部年级、局部单元的资料

这意味着它们适合 `整理和校对`，但不适合直接当作“官方完整数据源”。

## 可参考的公开来源

### 1. 学校老师公开的 Wonders 周词汇页

- [Mrs. Resener's Class - Reading Wonders](https://resenerj.weebly.com/reading-wonders.html)

这类页面通常按 `Unit / Week` 列出：

- Vocabulary
- High Frequency Words
- 技能点和主题

优点：

- 能看到每周目标词
- 结构接近实际教学安排

限制：

- 不一定覆盖全学段
- 版本和地区可能不同

### 2. 老师网页汇总到 weekly outline PDF

- [Mrs. Cugini 3rd Grade - Wonders Unit 4](https://cuginiteach.weebly.com/wonders-unit-4.html)

这个页面链接到 `theteachersguide.com` 的 weekly outline PDF。

优点：

- 通常按单元和周次整理
- 便于人工检查

限制：

- 多是分散页面，需要批量整理

### 3. 学区公开的高频词 PDF

- [Grade 1 McGraw-Hill Wonders HFW List by Unit](https://westlabschool.org/ourpages/auto/2024/8/28/63119122/Grade_1_MGH_Wonders_HFW_List_by_Unit_Floridas_B_E_S_T__Standards.pdf)

优点：

- 有明确年级和单元结构
- 适合补高频词

限制：

- 这是高频词，不等于完整词汇词表

## 更完整但通常需要购买或授权的来源

### 4. Teachers Pay Teachers 的周词汇和整套 bundle

- [FREE Wonders Grade 5 Unit 1 Week 1](https://www.teacherspayteachers.com/Product/FREE-Wonders-Words-to-Know-Grade-5-Unit-1-Week-1-PDFEasel-Activity-5892629)
- [Wonders Grade 5 Unit 1 Week 5](https://www.teacherspayteachers.com/Product/Wonders-Words-to-Know-Grade-5-Unit-1-Week-5-PDF-Easel-Activity-5892712)
- [Wonders Grades 1-6 Mega Bundle](https://www.teacherspayteachers.com/Product/Wonders-Words-to-Know-Grades-1-6-MEGA-BUNDLE-PDF-Easel-Activities-6026984)

优点：

- 覆盖范围可能更全
- 常按年级、单元、周次组织

限制：

- 通常是付费资源
- 使用方式需要遵守资源版权条款

## 推荐做法

如果你希望把应用做成“完整小学 Wonders 词库”，最稳妥的顺序是：

1. 先收集你能合法使用的词表来源
2. 用导入页面把 `grade / unit / week / word` 批量导进来
3. 再逐步补中文释义、儿童解释、例句、辨析卡

## 不建议的做法

- 直接复制教材原文例句和文章
- 未确认版权就批量抓取整套商业资源
- 混用不同版本的 Wonders 而不做版本标记
